## 3. Secure File Upload Workflow (S3)

To ensure S3 credentials are never exposed, implement the **Pre-signed URL flow**:

1.  **Request**: App calls `GET /api/v1/storage/upload-url?filename=room.jpg`.
2.  **Logic**: Server verifies auth, then uses its internal `S3_ACCESS_KEY` to generate a temporary `PUT` URL.
3.  **App Upload**: The mobile app uploads the file directly to the provided URL (direct upload to S3).
4.  **Registration**: Once uploaded, the App sends the file metadata to `POST /api/v1/history` to save the record.
